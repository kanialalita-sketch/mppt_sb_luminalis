🌅 Daily Standup Meeting

⏱️ Duration: 15 menit • 📅 Frequency: Setiap hari kerja • 👥 Participants: Development Team

Meeting Format

Setiap anggota tim menjawab 3 pertanyaan:

  1. What did I accomplish yesterday?
  2. What will I do today?
  3. Are there any impediments in my way?

Example: Daily Standup Log - Sprint 1, Day 1

Today:

📋 Sprint Planning Meeting

⏱️ Duration: 4 jam • 📅 Frequency: Awal setiap sprint • 👥 Participants: PO, SM, Dev Team

Agenda

Part 1: What can we deliver? (2 hours)

  1. Review Product Backlog
  2. Define Sprint Goal
  3. Select User Stories for Sprint
  4. Estimate Team Velocity
  5. Commit to Sprint Backlog

Part 2: How will we do it? (2 hours)

  1. Break down User Stories into Tasks
  2. Assign Story Points
  3. Identify Dependencies
  4. Assign Tasks to Team Members
  5. Finalize Sprint Backlog

🔄 Sprint Retrospective

⏱️ Duration: 1.5 jam • 📅 Frequency: Setelah Sprint Review • 👥 Participants: Dev Team, SM

Format: Start-Stop-Continue

Sprint 1 Retrospective Results

Date: 30 Juni 2026

START (What should we start doing?)

✅ Start peer code reviews before merging

Rationale: Caught several bugs late in sprint
Action: Implement mandatory 2-reviewer approval
Owner: Tech Lead • Due: Before Sprint 2 starts

✅ Start daily automated smoke tests

Rationale: Integration issues detected late
Action: Configure nightly test runs
Owner: QA Lead • Due: Week 1 Sprint 2

STOP (What should we stop doing?)

❌ Stop late-sprint large commits

Issue: Hard to review, risky deployments
Action: Enforce commit size limits
Owner: Scrum Master • Due: Immediate

❌ Stop skipping unit tests for "quick fixes"

Issue: Technical debt accumulation
Action: Block merges without tests
Owner: DevOps (Pipeline config) • Due: Week 1 Sprint 2

CONTINUE (What's working well?)

  • ✔ Daily standups at 9 AM - Good team sync, blockers resolved quickly
  • ✔ Weekly stakeholder updates - Keeps management informed and supportive
  • ✔ Pair programming for complex features - Knowledge sharing, fewer bugs
  • ✔ Slack channels for async communication - Reduces meeting overhead
